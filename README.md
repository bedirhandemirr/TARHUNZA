# TARHUNZA 
#  Kampüs Etkinlik Yönetim Sistemi

Üniversite kulüplerinin ve öğrencilerinin kampus içi etkinlikleri kolayca düzenlemesini, takip etmesini ve katılmasını sağlayan masaüstü uygulaması.

##  Özellikler

- **Kullanıcı Rolleri:** Öğrenci ve kulüp yöneticisi için ayrı paneller.
- **Etkinlik Oluşturma ve Takip:** Tarih, konum ve detay bilgisiyle etkinlik ekleme/düzenleme.
- **Kayıt Sistemi:** Öğrencilerin tek tıkla etkinliklere kaydolabilmesi ve katılım kodu alması.
- **Duyuru Sistemi:** Etkinlik güncellemelerinden ve iptallerinden anında haberdar olma.

##  Kullanılan Teknolojiler

- **Dil:** Java
- **Arayüz:** JavaFX(SceneBuilder) / Swing
- **Veri Saklama:** Özel Metin Dosyası Depolama (Custom Text File I/O)<-sor
